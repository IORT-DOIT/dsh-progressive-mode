# Implementation Planning

规划深度必须匹配风险。

## Level 2

至少说明： - 修改范围 - 依赖关系 - 实施顺序 - 关键工件 - 验证方式 -
不修改区域

## Level 3

增加： - 当前状态 - 目标状态 - 影响面 - 不变量 - 迁移策略 - 验证方案

## Level 4

增加： - 为什么需要架构变化 - 替代方案 - 架构权衡 - 兼容策略 -
分阶段迁移 - 回滚方案

不要对低风险任务强制执行高级设计。
